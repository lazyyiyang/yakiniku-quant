# A股市场微观结构与委托机制

> 理解A股的订单簿和成交机制，是优化执行的前提

## A股订单类型

| 订单类型 | 说明 | 用途 |
|----------|------|------|
| 限价单 | 指定价格买卖 | 控制成交价格 |
| 市价单（最优5档） | 以最优5档价格成交 | 快速成交 |
| 市价单（最优5档即时成交剩余撤销） | 以5档成交，剩余撤单 | 控制滑点 |
| 市价单（全额成交或撤销） | 要么全部成交，要么不成交 | 大单执行 |

**A股特殊性**：
- 没有纳斯达克那样的做市商制度
- 集合竞价产生开盘价
- 涨跌停板限制订单成交价格范围
- T+1限制了日内回转（ETF除外）


## 订单簿结构

```
卖5  25.05  3000股  ────
卖4  25.04  2500股  ────
卖3  25.03  5000股  ────
卖2  25.02  8000股  ────
卖1  25.01 10000股  ────  ← 最优卖价（Ask）
────────────────────────
买1  25.00  12000股  ────  ← 最优买价（Bid）
买2  24.99  7000股   ────
买3  24.98  4000股   ────
买4  24.97  3000股   ────
买5  24.96  2000股   ────

买卖价差 = 25.01 - 25.00 = 0.01元（1分钱）
中间价 = (25.01 + 25.00) / 2 = 25.005元
```

### 关键微观结构指标

```
买卖价差（Bid-Ask Spread）：
  衡量即时流动性
  A股大盘股：1-2分钱（约0.04-0.08%）
  A股小盘股：5-10分钱（约0.5-1%）

订单簿深度（Depth）：
  各价格档的挂单量
  深度不足 → 大单冲击成本高

订单流不平衡（Order Flow Imbalance）：
  买方挂单量 vs 卖方挂单量
  买方力压 → 价格可能上涨
  卖方力压 → 价格可能下跌
```


## 集合竞价机制

```
9:15-9:20：可挂单可撤单（虚晃期）
9:20-9:25：可挂单不可撤单（真实期）
9:25-9:30：不接受申报
9:30：连续竞价开始

14:57-15:00：收盘集合竞价
```

### 集合竞价定价规则

```
1. 最大化成交量原则
2. 使高于成交价的买入和低于成交价的卖出全部成交
3. 与成交价相同的买方/卖方至少一方全部成交

量化利用：
- 9:25的开盘价 = 隔夜信息的浓缩
- 开盘跳空方向和幅度 = 短期信号
- 集合竞价量 = 市场关注度
```


## 流动性分类

| 股票类型 | 日均成交额 | 买卖价差 | 冲击成本(1%市值) |
|----------|-----------|---------|----------------|
| 超大盘（茅台等） | > 50亿 | 0.01-0.02元 | < 5 bps |
| 大盘蓝筹 | 5-50亿 | 0.01-0.05元 | 5-20 bps |
| 中盘股 | 0.5-5亿 | 0.02-0.10元 | 20-50 bps |
| 小盘股 | 0.05-0.5亿 | 0.05-0.50元 | 50-200 bps |
| 微盘股 | < 500万 | > 0.10元 | > 200 bps |

**量化策略的流动性门槛**：
- 日策略：日均成交额 > 1亿
- 周策略：日均成交额 > 5000万
- 月策略：日均成交额 > 1000万


## A股特有的微观结构现象

### 1. 涨跌停板的影响

```
- 涨停封板：买一挂单巨大，卖单稀少
  → 买入困难，执行成本高
  → 涨停板策略需要集合竞价参与

- 跌停封板：卖一挂单巨大，买单稀少
  → 卖出困难，流动性枯竭
  → 回测中必须模拟无法成交

量化影响：
  → 涨跌停板是A股最大的执行摩擦
  → 做多策略在涨停时无法建仓
  → 止损策略在跌停时无法执行
```

### 2. 尾盘拉升/杀跌

```
14:30-15:00 尾盘异动：
- 机构做净值：季末/年末尾盘拉升重仓股
- 尾盘杀跌：融资盘强平
- 收盘集合竞价：最后3分钟变更成交价

量化应对：
- 不在最后30分钟执行大单
- 收盘价取集合竞价结果
```

### 3. 开盘跳空

```
9:25开盘价的含义：
- 跳空高开 > 1%：强烈看涨信号
- 跳空低开 < -1%：强烈看跌信号
- 开盘跳空幅度 = (开盘价 - 前收盘) / 前收盘

日线策略应使用开盘价作为可成交价（非收盘价）
```


## ETF微观结构

```
ETF特有的微观结构：
1. 一级市场申购赎回（套利机制）
2. ETF折溢价 = ETF价格 vs 净值
3. ETF T+0 回转交易

ETF折溢价套利：
- ETF价格 > 净值（溢价）：
  买入一篮子股票 → 申购ETF → 卖出ETF
  
- ETF价格 < 净值（折价）：
  买入ETF → 赎回一篮子股票 → 卖出股票

套利门槛：
- 一级市场最低30万-100万份
- 需要实时IOPV数据
- 需要考虑成分股涨跌停限制
```
