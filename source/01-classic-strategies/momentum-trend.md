# 动量与趋势跟踪策略

> 最古老、最被验证的交易策略之一

## 核心原理

动量策略的核心假设：**过去表现好的资产在未来一段时间内仍会继续表现好**。

- 价格具有自相关性（短期正、长期负）
- 信息扩散需要时间，投资者反应不足
- 行为金融解释：锚定效应、处置效应

## 经典动量策略

### 1. 截面动量（Cross-Sectional Momentum）

最经典的动量策略，Jegadeesh & Titman (1993)：

```
每月末：
1. 计算所有股票过去J个月的收益（形成期）
2. 按收益排序，买入前10%（赢家组合），卖空后10%（输家组合）
3. 持有K个月（持有期）
4. 典型参数：J=3~12, K=1~12
```

**A股注意**：
- A股融券限制多，纯空头难以实现
- 改为只做多赢家组合（纯多头动量）
- 或使用ETF/股指期货对冲

### 2. 时序动量（Time-Series Momentum）

Moscovitz, Ooi, Pedersen (2012)：

```
每月末：
1. 计算资产自身过去J个月的收益
2. 如果收益为正 → 做多；收益为负 → 做空
3. 典型参数：J=12, K=1
```

**优势**：不需要横截面比较，可直接应用于个股、ETF、期货

### 3. 均线交叉策略

最直觉的趋势跟踪：

```
短期均线（如20日）上穿长期均线（如60日）→ 买入
短期均线下穿长期均线 → 卖出
```

**变体**：
- 双均线交叉：MA(5)/MA(20)，MA(10)/MA(60)
- 价格 vs 均线：价格站上均线做多，跌破做空
- 多均线排列：MA5 > MA10 > MA20 > MA60 = 多头排列

### 4. 海龟交易法（Turtle Trading）

Richard Dennis 的经典趋势系统：

```
入场规则：
- 系统1：价格突破20日最高价做多，跌破20日最低价做空
- 系统2：55日突破（更长期）

止损规则：
- 系统1：10日反向突破
- 系统2：20日反向突破

仓位管理：
- 风险头寸 = 账户风险% / (N × 合约乘数)
- N = ATR(20)，即20日平均真实波幅
- 最多加仓4次，每次0.5N间隔
```

### 5. 通道突破策略（Donchian Channel）

```
上轨 = HH(20)  // 20日最高价
下轨 = LL(20)  // 20日最低价

价格突破上轨 → 做多
价格跌破下轨 → 做空
```


## A股动量特征

| 特征 | 说明 |
|------|------|
| 短期反转 | A股1个月内存在显著反转效应（J=1时动量为负） |
| 中期动量 | 3-12个月形成期有正动量效应 |
| 涨跌停限制 | 涨跌停板影响信号判定和执行 |
| 换手率高 | A股换手率远高于成熟市场 |
| 散户占比高 | 行为偏差导致的动量/反转模式更明显 |
| 融券限制 | 卖空成本高，纯多头动量更实际 |

## 关键参数与陷阱

### 参数敏感性

- **形成期**：1个月（反转）、3-6个月（短期动量）、12个月（经典动量）
- **持有期**：1个月（高频）、3-6个月（中频）
- **再平衡频率**：月度（典型）、周度（更活跃）
- **研究来源**：参数选择必须有理论依据，不能纯数据拟合

### 常见陷阱

| 陷阱 | 说明 | 对策 |
|------|------|------|
| 过度拟合 | 参数搜索空间太大 | 限制参数数量，Walk-forward验证 |
| 幸存者偏差 | 只用存活股票 | 加入退市股票数据 |
| 交易成本 | 忽略滑点佣金 | 详细建模，尤其是换手率高时 |
| 时点异常 | 季节效应、节假日 | 控制日历效应 |
| 动量崩溃 | 趋势突然反转 | 设置止损，加入波动率过滤 |

## 与其他策略的结合

- **动量 + 价值**：低估值+高动量组合是最经典的Smart Beta策略
- **动量 + 波动率**：低波动率环境下动量更有效
- **动量 + 择时**：均值回归环境下降低动量敞口
