# 均值回归与反转策略

> 价格偏离均衡后的回归是市场最基础的统计规律之一

## 核心原理

均值回归假设：**价格偏离均值后，终将回归均值水平**。

- 统计基础：协整关系、平稳性、ADF检验
- 行为学解释：过度反应后修正
- 适用环境：震荡市、区间波动

**关键区别**：
- 动量策略赚取的是趋势延续
- 均值回归策略赚取的是过度反应的修正

## 经典均值回归策略

### 1. 均线偏离策略

```
计算价格偏离MA(N)的百分比：
  deviation = (price - MA(N)) / MA(N)

当 deviation < -threshold → 买入（价格低于均线过多）
当 deviation > +threshold → 卖出（价格高于均线过多）
当 deviation ≈ 0 → 离场

典型参数：N=20, threshold=2~3个标准差
```

即布林带策略的标准形式。

### 2. RSI 超买超卖策略

```
RSI(14) < 30 → 超卖区域，买入信号
RSI(14) > 70 → 超买区域，卖出信号

变体：
- RSI背离：价格新低但RSI不新低 → 看涨背离
- 中轴线策略：RSI突破50做多，跌破50做空
```

### 3. 配对交易（详见 pairs-stat-arb.md）

最经典的均值回归策略：
- 找到两个协整的资产
- 价差偏离均值时做空强势、做多弱势
- 价差回归时平仓获利

### 4. A股特有的均值回归

#### 涨跌停反转

```
涨停板次日策略：
- 涨停板次日开盘买入（集合竞价）
- 持有1-5日
- A股涨停板有信息含量和过度反应

跌停板反转策略：
- 连续跌停后的开板日超跌反弹
- 风险较高，需严格止损
```

#### 换手率反转

```
高换手率后反转：
- 异常高换手率（>2倍平均）次日倾向于下跌
- 低换手率突破后倾向于继续
```

#### 融资融券余额反转

```
融资余额极端 → 反向信号
- 融资余额过快增长 → 均值回归卖出信号
- 融资余额急速下降 → 均值回归买入信号
```


## 统计基础

### 平稳性检验（ADF检验）

均值回归的前提是价差序列平稳：

```python
from statsmodels.tsa.stattools import adfuller

result = adfuller(spread_series)
p_value = result[1]

if p_value < 0.05:
    # 序列平稳 → 均值回归可能有效
    pass
else:
    # 序列非平稳 → 均值回归策略风险大
    pass
```

### 半衰期计算

```
spread_lag = spread.shift(1)
spread_diff = spread.diff()

model: spread_diff = λ × spread_lag + ε

half_life = -ln(2) / λ

半衰期越短 → 回归速度越快 → 策略换手越高
半衰期过长 → 回归太慢 → 资金效率低
A股市面：半衰期 5-30天 的策略较实用
```

## 均值回归的风险

| 风险 | 说明 | 对策 |
|------|------|------|
| 趋势崩塌 | 均值回归在趋势市中亏损 | 加入趋势过滤，趋势市不做回归 |
| 结构性变化 | 均值本身发生变化 | 滚动窗口重新估计均值 |
| 过早入场 | 猜测底部/顶部 | 等待确认信号（如RSI背离） |
| 杠杆风险 | 配对交易需双倍敞口 | 控制总杠杆，设定止损 |
| 协整断裂 | 历史协整关系失效 | 监测协整关系，设置断裂止损 |

## 策略互补

| 市场环境 | 动量策略 | 均值回归策略 |
|----------|---------|------------|
| 趋势市 | 盈利 | 亏损 |
| 震荡市 | 亏损 | 盈利 |
| 混合市 | 看周期 | 看周期 |

**建议**：动量与均值回归策略组合使用，用波动率或ADX判断市场状态来切换。
