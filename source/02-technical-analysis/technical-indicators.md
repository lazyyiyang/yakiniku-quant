# 技术指标大全

> 将价格和成交量转化为可量化、可回测的信号

## 指标分类

| 类别 | 代表指标 | 核心逻辑 |
|------|---------|---------|
| 趋势型 | MA, MACD, ADX | 跟踪趋势方向 |
| 动量型 | RSI, KDJ, Williams %R | 衡量价格变动速度 |
| 波动率型 | 布林带, ATR | 衡量价格波动范围 |
| 成交量型 | OBV, VWAP | 确认价格走势的量能 |
| 支撑阻力型 | 枢轴点, 斐波那契 | 寻找关键价格位置 |


## 趋势型指标

### 移动平均线（MA）

**简单移动平均（SMA）**：
```python
SMA(N) = sum(close[-N:]) / N
```

**指数移动平均（EMA）**：更重视近期价格
```python
EMA(today) = α × close + (1-α) × EMA(yesterday)
α = 2 / (N + 1)
```

**常用 MA 参数**：
| 周期 | 含义 | 用途 |
|------|------|------|
| MA5/MA10 | 短期 | 超短期趋势 |
| MA20 | 月线 | 中短期趋势 |
| MA60 | 季线 | 中期趋势 |
| MA120 | 半年线 | 中长期趋势 |
| MA250 | 年线 | 长期趋势，牛熊分界 |

**均线交易信号**：
- 金叉：短期MA上穿长期MA → 看涨
- 死叉：短期MA下穿长期MA → 看跌
- 多头排列：MA5 > MA10 > MA20 > MA60 → 强趋势
- 空头排列：MA5 < MA10 < MA20 < MA60 → 强下降趋势

### MACD（指数平滑异同移动平均线）

```
DIF = EMA(12) - EMA(26)          // 快慢均线差
DEA = EMA(DIF, 9)                 // DIF的9日EMA
MACD柱 = 2 × (DIF - DEA)         // 红绿柱

信号：
1. DIF上穿DEA → 金叉，看涨
2. DIF下穿DEA → 死叉，看跌
3. MACD柱由绿转红 → 动能转多
4. DIF与价格背离 → 顶/底背离信号
```

**顶背离**：价格创新高，DIF未创新高 → 趋势减弱
**底背离**：价格创新低，DIF未创新低 → 下跌动能减弱

### ADX（平均趋向指数）

```
ADX 衡量趋势强度（非方向）：
- ADX < 20：无趋势（震荡市）
- ADX 20-40：趋势形成
- ADX > 40：强趋势
- ADX > 60：极强趋势

用途：判断市场状态 → 决定使用趋势策略还是均值回归策略
```


## 动量型指标

### RSI（相对强弱指标）

```
RSI(N) = 100 - 100/(1 + RS)
RS = 平均涨幅 / 平均跌幅

常用参数：N=14（默认）、N=6（更敏感）

信号：
- RSI > 70：超买区（但超强趋势中可长期>70）
- RSI < 30：超卖区
- RSI背离：价格与RSI方向不一致 → 反转信号
- RSI中轴50：多方/空方分界
```

### KDJ（随机指标）

```
RSV = (C - Ln) / (Hn - Ln) × 100
K = 2/3 × K_prev + 1/3 × RSV
D = 2/3 × D_prev + 1/3 × K
J = 3K - 2D

常用参数：N=9, M1=3, M2=3

信号：
- K>D 金叉看涨，K<D 死叉看跌
- J>100 超买，J<0 超卖
- KDJ在20以下金叉更可靠
```

### Williams %R

```
%R = (Hn - C) / (Hn - Ln) × (-100)

范围：-100 到 0
- %R > -20：超买
- %R < -80：超卖
与KDJ高度相关
```


## 波动率型指标

### 布林带（Bollinger Bands）

```
中轨 = MA(N)           // 通常 N=20
上轨 = 中轨 + K×σ      // K通常=2
下轨 = 中轨 - K×σ

σ = 标准差(N)

信号：
- 价格触及上轨 → 超买/趋势过强
- 价格触及下轨 → 超卖/趋势过弱
- 布林带收窄 → 即将变盘（波动率压缩）
- 布林带扩张 → 趋势启动

布林带 + RSI：
- 价格>上轨 且 RSI>70 → 强超买
- 价格<下轨 且 RSI<30 → 强超卖
```

### ATR（平均真实波幅）

```
TR = max(H-L, |H-C_prev|, |L-C_prev|)
ATR(N) = SMA(TR, N)    // 通常 N=14

用途：
- 止损设置：入场价 ± K×ATR
- 仓位计算：风险金额 / ATR = 持仓股数
- 波动率判断：ATR急剧扩大 → 异常波动
- 海龟交易法使用ATR进行仓位管理
```


## 成交量型指标

### OBV（能量潮）

```
如果收盘价上涨：OBV += 成交量
如果收盘价下跌：OBV -= 成交量
如果收盘价不变：OBV 不变

信号：
- 价格上涨 且 OBV创新高 → 健康上涨
- 价格创新高 但 OBV未创新高 → 顶背离（看跌）
- 价格下跌 但 OBV上升趋势 → 底背离（看涨）
```

### VWAP（成交量加权平均价）

```
VWAP = Σ(price × volume) / Σ(volume)

用途：
- 机构执行基准：买入价低于VWAP为优
- 支撑阻力位
- 日内交易参考

注意：VWAP随时间推移越来越稳定，午后信号减弱
```


## 支撑阻力型指标

### 枢轴点（Pivot Points）

```
中枢位 PP = (H + L + C) / 3
第一阻力 R1 = 2×PP - L
第一支撑 S1 = 2×PP - H
第二阻力 R2 = PP + (H - L)
第二支撑 S2 = PP - (H - L)
```

### 斐波那契回撤

```
关键回撤位：23.6%, 38.2%, 50%, 61.8%, 78.6%

计算：从一段趋势的低点到高点，画出回撤位
- 38.2%：浅回撤，强趋势
- 50%：中等回撤
- 61.8%：深回撤，常见支撑位（黄金分割比）
```


## 指标使用原则

1. **不要组合使用太多指标** — 3-4个足够，太多等于没有
2. **趋势指标 + 动量指标 + 成交量** — 经典三元组合
3. **先判断市场状态** — 用ADX/布林带宽度判断趋势 vs 震荡
4. **指标是辅助工具** — 价格和成交量是第一性原理
5. **参数敏感性测试** — 如果微调参数就完全改变结论，信号不可靠
6. **多周期确认** — 日线信号 + 周线方向 一致时更可靠
