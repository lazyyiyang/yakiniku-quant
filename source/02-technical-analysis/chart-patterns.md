# 图表形态分析

> 价格形态反映市场心理，是技术分析的经典组成部分

## 形态分类

| 形态 | 类别 | 含义 |
|------|------|------|
| 头肩顶/底 | 反转 | 趋势反转 |
| 双顶/双底 | 反转 | M顶/W底 |
| 三角形 | 持续/反转 | 收敛后突破 |
| 旗形/三角旗 | 持续 | 短暂休整后继续 |
| 矩形 | 持续 | 横盘蓄势 |
| 圆弧顶/底 | 反转 | 缓慢转向 |


## 反转形态

### 头肩顶（Head and Shoulders Top）

```
价格走势：

           左肩顶
          /     \
         /       \      头部顶
        /         \    /     \
───────/───────────\──/───────\────── 颈线
                    \         /
                     \───────/    右肩
                              右肩底

要素：
1. 左肩：价格上涨后回调
2. 头部：价格再创新高后回调
3. 右肩：价格未能创新高（头部低点=颈线）
4. 跌破颈线：确认反转

目标跌幅 = 头部顶点 - 颈线（从突破点向下）
```

**成交量确认**：
- 左肩：量能正常
- 头部：量能小于左肩（量价背离）
- 右肩：量能进一步萎缩
- 突破颈线：放量下跌

### 头肩底（Inverse Head and Shoulders）

头肩顶的镜像，出现在下跌趋势底部。

**与头肩顶的区别**：
- 底部形态右肩放量更可靠
- 突破颈线需要放量确认
- A股底部形态中更常见有效突破

### 双顶（M顶）/ 双底（W底）

```
双顶（M顶）：

     高点1          高点2
      /\              /\
     /  \            /  \
    /    \          /    \
───/──────\────────/──────\─── 颈线（两低点连线）

确认：
- 第二次未创新高
- 跌破颈线确认
- 颈线破位放量更可靠

双底（W底）为M顶的镜像
```

**A股特征**：
- 双底比双顶更常见（A股散户偏多，恐慌性底部更明显）
- 第二底缩量是底部信号
- 突破颈线放量确认是必要条件


## 持续形态

### 三角形

```
上升三角形（看涨）：      下降三角形（看跌）：
    ─────────────         \                /
    /\              \       \              /
   /  \              \       \            /
  /    \              \      \──────────/
 /      \────────      \

突破方向：
- 上升三角形：大概率向上突破
- 下降三角形：大概率向下突破
- 对称三角形：方向不确定

目标涨幅 = 三角形底边宽度（从突破点起算）
```

**交易规则**：
- 在三角形2/3位置突破最可靠
- 突破时成交量应明显放大
- 假突破后再反转更强烈

### 旗形与三角旗

```
看涨旗形（Bull Flag）：

 ━━━━━━ 急涨
 ╲
  ╲  旗形（缓缓回调）
   ╲
    ╲━━━ 突破继续上涨

特点：
- 急涨后的短暂回调
- 回调幅度约1/3到1/2
- 回调时间约5-20天
- 突破后涨幅约等于旗杆长度
```

### 矩形（箱体整理）

```
 ━━━━━━━━━━ 箱顶阻力
 │         │
 │  箱体内  │
 │  震荡    │
 │         │
 ━━━━━━━━━━ 箱底支撑

交易：
- 在箱底买入，箱顶卖出（区间交易）
- 或等待方向突破
- 突破后目标 = 箱体高度
```


## 缺口（跳空）

| 缺口类型 | 位置 | 含义 |
|----------|------|------|
| 普通缺口 | 整理区内 | 几天内回补，意义不大 |
| 突破缺口 | 形态突破时 | 趋势启动，不回补 |
| 测量缺口 | 趋势中段 | 趋势持续，目标位参考 |
| 衰竭缺口 | 趋势末端 | 最后冲刺，即将反转 |

**A股特殊性**：
- A股涨跌停板限制→缺口更常见但信息含量参差
- 向上跳空缺口 + 涨停 = 极强信号
- 向下跳空缺口 + 利空 → 可能连续跌停


## 形态分析的量化验证

传统图表形态主观性强，但可以量化：

```python
def detect_double_bottom(prices, tolerance=0.03):
    """
    量化检测W底形态
    """
    # 找局部极小值
    from scipy.signal import argrelextrema
    local_mins = argrelextrema(prices.values, np.less, order=20)[0]

    if len(local_mins) < 2:
        return None

    # 检测两个底是否接近
    for i in range(len(local_mins) - 1):
        min1, min2 = local_mins[i], local_mins[i+1]
        price1, price2 = prices.iloc[min1], prices.iloc[min2]

        # 两底价格差在容差范围内
        if abs(price1 - price2) / max(price1, price2) < tolerance:
            # 颈线 = 两底之间的高点
            neckline = prices.iloc[min1:min2].max()

            return {
                'bottom1_idx': min1,
                'bottom2_idx': min2,
                'bottom1_price': price1,
                'bottom2_price': price2,
                'neckline': neckline,
                'target': neckline + (neckline - min(price1, price2))
            }

    return None
```


## 形态分析注意事项

1. **形态失败是最重要的信号** — 看涨形态失败 = 强看跌信号
2. **量能确认是关键** — 没有放量的突破不可信
3. **时间框架** — 周线形态比日线形态更可靠
4. **不要强加形态** — 不是每段行情都有清晰形态
5. **概率思维** — 形态是概率优势，不是确定性
6. **结合基本面** — 技术形态+A股政策面 比纯技术更有效
