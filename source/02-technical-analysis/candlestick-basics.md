# K线基础与蜡烛图形态

> 东方技术分析的基石，每一根K线都讲述着多空博弈的故事

## K线的构成

```
    ┌─── 上影线（最高价 - 实体上端）
    │
┌───┤
│   │  实体（开盘价 ↔ 收盘价）
└───┤
    │
    └─── 下影线（实体下端 - 最低价）

阳线（收盘 > 开盘）：实体为空或绿色
阴线（收盘 < 开盘）：实体为实或红色

注：A股红涨绿跌，与美股惯例相反
```

**四要素**：开盘价、收盘价、最高价、最低价

**关键信息**：
- 实体长度 → 多空力量对比
- 上下影线 → 试探与犹豫
- K线组合 → 趋势信号


## 单根K线形态

### 看涨形态

| 形态 | 特征 | 信号强度 | 出现位置 |
|------|------|---------|---------|
| 大阳线 | 长实体，短影线 | ★★★ | 底部反转或趋势确认 |
| 锤子线 | 长下影线，短上影线，小实体 | ★★★ | 下跌趋势底部 |
| 倒锤子 | 长上影线，短下影线，小实体 | ★★ | 下跌趋势底部 |
| 早晨之星 | （见组合形态） | ★★★ | 下跌趋势底部 |

### 看跌形态

| 形态 | 特征 | 信号强度 | 出现位置 |
|------|------|---------|---------|
| 大阴线 | 长实体，短影线 | ★★★ | 顶部反转或趋势确认 |
| 上吊线 | 长下影线，小实体在顶部 | ★★★ | 上涨趋势顶部 |
| 射击之星 | 长上影线，小实体在底部 | ★★★ | 上涨趋势顶部 |
| 黄昏之星 | （见组合形态） | ★★★ | 上涨趋势顶部 |

### 中性/犹豫形态

| 形态 | 特征 | 含义 |
|------|------|------|
| 十字星 | 开盘≈收盘，有上下影线 | 犹豫不决，可能转向 |
| 纺锤线 | 小实体，长上下影线 | 多空平衡 |
| 四价合一 | 开盘=收盘=最高=最低 | 无信息（A股很少见） |


## 组合K线形态

### 反转形态

#### 吞没形态（Engulfing）
```
看涨吞没（底部）：
    ┌─┐
    │ │  阴线
┌───┤ ├───┐
│   │ │   │  阳线完全包住阴线
└───┤ ├───┘
    │ │
    └─┘

信号：阳线实体完全包住前一根阴线实体
可靠性：★★★ 出现在趋势末端时更可靠
```

#### 启明星/黄昏星（Morning/Evening Star）
```
看涨启明星：
    ┌─┐
    │ │  大阴线
    └─┘
     ─    小星线（十字星最佳）
  ┌───┐
  │   │  大阳线
  └───┘

信号：大阴线 + 小实体 + 大阳线，阳线深入阴线的50%以上
可靠性：★★★
```

#### 三白兵/三黑鸦
```
三白兵（看涨）：连续三根阳线，每根开盘在前一根实体内
三黑鸦（看跌）：连续三根阴线，每根开盘在前一根实体内

可靠性：★★★ 趋势延续信号
```

### 持续形态

| 形态 | 含义 |
|------|------|
| 窗口（跳空缺口） | 趋势加速，缺口为支撑/阻力 |
| 上升三法 | 短暂回调后趋势继续 |
| 下降三法 | 短暂反弹后趋势继续 |


## K线分析的原则

### 1. 位置比形态更重要

- 锤子线出现在底部 = 看涨信号
- 锤子线出现在顶部 = 上吊线 = 看跌信号
- **同样的K线在不同位置，含义完全不同**

### 2. 需要确认

- 单根K线信号较弱，需要后续K线确认
- 放量确认比缩量更可靠
- 与技术指标配合使用效果更好

### 3. 周期含义

| 周期 | K线意义 |
|------|---------|
| 日线 | 短期信号（1-5天） |
| 周线 | 中期信号（1-4周） |
| 月线 | 长期信号（1-3月） |
| 60分钟 | 超短期（1-2天） |

### 4. A股特殊性

- 涨跌停K线：开盘即封板 = 超强信号
- 集合竞价跳空：9:15-9:25信息含量
- 尾盘异动：14:30之后的信号需谨慎解读


## K线与成交量的配合

### 价量关系基石

```
量增价升 → 健康上涨（买盘积极）
量缩价升 → 上涨乏力（需警惕）
量增价跌 → 恐慌抛售或主力出货
量缩价跌 → 下跌动能减弱（可能见底）
天量天价 → 顶部信号
地量地价 → 底部信号
```

### 成交量确认规则

1. **突破需放量**：价格突破关键位时，成交量应明显放大（1.5-2倍均量）
2. **回调可缩量**：趋势中的回调，成交量应萎缩
3. **背离信号**：价格新高但量能低于前高 → 顶部背离，看跌
4. **OBV指标**：能量潮指标，价量背离的量化工具
