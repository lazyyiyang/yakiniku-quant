# 期权入门与定价

> 期权是对冲的基础工具，理解定价是使用期权的前提

## 期权基础概念

### 看涨与看跌

```
看涨期权（Call）：买入权利，以约定价格买入标的
看跌期权（Put）：买入权利，以约定价格卖出标的

Buys Call：看大涨（付出权利金）
Buys Put：看大跌（付出权利金）
Sells Call：看不涨（收取权利金）
Sells Put：看不跌（收取权利金）
```

### 关键术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 行权价 | Strike Price | 约定的买卖价格 |
| 到期日 | Expiration | 期权有效截止日 |
| 权利金 | Premium | 期权的价格 |
| 内在价值 | Intrinsic Value | 立即行权的收益 |
| 时间价值 | Time Value | 权利金 - 内在价值 |
| 实值 | In-the-Money (ITM) | 有内在价值 |
| 平值 | At-the-Money (ATM) | 行权价≈标的价 |
| 虚值 | Out-of-Money (OTM) | 无内在价值 |

## Black-Scholes 定价模型

```
Call = S × N(d1) - K × e^(-rT) × N(d2)
Put  = K × e^(-rT) × N(-d2) - S × N(-d1)

d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d2 = d1 - σ√T

其中：
S = 标的资产当前价格
K = 行权价
r = 无风险利率
T = 到期时间（年）
σ = 波动率
N() = 标准正态分布CDF
```

### BS模型的假设与现实

| 假设 | 现实 | 影响 |
|------|------|------|
| 波动率恒定 | 波动率聚簇、波动率微笑 | BS定价偏差 |
| 连续交易 | 涨跌停、交易暂停 | 跳空风险 |
| 无交易成本 | 佣金、滑点、保证金 | 实际成本更高 |
| 欧式行权 | A股是欧式，符合 | 无影响 |
| 对数正态分布 | 收益率有肥尾 | OTM期权BS低估 |


## Greeks（希腊字母）

### Delta (Δ)

```
定义：期权价格对标的价格的偏导数
      Δ = ∂C/∂S

含义：标的涨1元，期权涨Δ元
看涨：0 < Δ < 1（ATM ≈ 0.5）
看跌：-1 < Δ < 0（ATM ≈ -0.5）

用途：
- 方向敞口度量
- Delta中性对冲：持有Δ份标的抵消方向风险
- 例如：买入1张Call(Δ=0.5) → 做空0.5份标的实现Delta中性
```

### Gamma (Γ)

```
定义：Delta对标的价格的偏导数（价格的二阶偏导）
      Γ = ∂²C/∂S²

含义：Delta的变化速度
- ATM期权Gamma最大
- 接近到期时Gamma急剧增大
- Gamma = 价格加速器的开关

风险管理：
- 做卖方的Gamma风险 → 标的大幅波动时Delta剧烈变化
- 做买方享受Gamma → 标的涨越多，Delta越大
```

### Theta (Θ)

```
定义：期权价格对时间的偏导数
      Θ = ∂C/∂t

含义：每过一天，期权损失Θ元时间价值
- 买方Θ为负（时间流逝对你不利）
- 卖方Θ为正（时间流逝对你有利）

特征：
- ATM期权Theta最大（绝对值）
- 越接近到期，Theta越大
- "期权时间衰减"的核心
```

### Vega (ν)

```
定义：期权价格对波动率的偏导数
      ν = ∂C/∂σ

含义：波动率上升1%，期权价格上升ν
- 买方Vega为正（波动率上升对你有利）
- 卖方Vega为负

特征：
- ATM期权Vega最大
- 远期期权Vega > 近期期权
- "做多波动率" = 买入Vega
```

|---|---|---|---|---|
| Delta | + | - | - | + |
| Gamma | + | + | - | - |

## 期权策略组合

### 四大基本策略

| 策略 | 看法 | 最大盈利 | 最大亏损 | 盈亏平衡 |
|------|------|---------|---------|---------|
| 买Call | 看大涨 | 无限 | 权利金 | K+权利金 |
| 买Put | 看大跌 | K-权利金 | 权利金 | K-权利金 |
| 卖Call | 看不涨 | 权利金 | 无限 | K+权利金 |
| 卖Put | 看不跌 | 权利金 | K-权利金 | K-权利金 |

### 风险有限策略

**牛市价差（Bull Call Spread）**：
```
买入低行权价Call + 卖出高行权价Call

盈亏：
- 标的大涨：盈利（有上限）
- 标的小涨/持平：小幅盈利或亏损
- 标的大跌：亏损（有上限=净权利金）

适合：温和看涨，降低买入Call的成本
```

**熊市价差（Bear Put Spread）**：
```
买入高行权价Put + 卖出低行权价Put

适合：温和看跌，降低买入Put的成本
```

**跨式/宽跨式（Straddle/Strangle）**：
```
跨式：买入ATM Call + ATM Put（大涨大跌都赚）
宽跨式：买入OTM Call + OTM Put（成本更低，需要更大波动）

适合：预期大幅波动但方向不明
风险：时间衰减 + 波动率下降
```

**铁鹰式（Iron Condor）**：
```
卖低行权价Put + 买更低Put + 卖高行权价Call + 买更高Call

适合：预期窄幅震荡
风险有限，收益有限
```

### 保护性看跌（Protective Put）

```
持有标的 + 买入Put
= 为持仓买保险

成本：Put的权利金
用途：对冲下跌风险（见 hedging-strategies.md）
```


## 波动率

### 隐含波动率（IV）vs 历史波动率（HV）

```
HV = 过去一段时间收益率的年化标准差
IV = 从期权市场价格反推的波动率

一般关系：
IV > HV：期权偏贵（可以考虑卖出波动率）
IV < HV：期权偏便宜（可以考虑买入波动率）
IV通常 > HV：风险溢价

A股特征：
- 50ETF期权IV长期高于HV约3-5个百分点
- 事件前IV跳升（政策、财报、假期）
- 事件后IV崩溃（IV Crush）
```

### 波动率微笑/偏斜

```
不同行权价的IV不同：
- 低行权价Put → IV偏高（恐慌效应）
- 高行权价Call → IV略高（肥尾效应）
- ATM → IV最低

A股波动率偏斜特征：
- 左偏更明显（恐慌性看跌需求更强）
- 越接近到期，偏斜越陡峭
```
