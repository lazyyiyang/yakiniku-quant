# 波动率与偏斜交易

> 波动率是期权市场最重要的变量，理解波动率就理解了期权定价的核心

## 波动率基础

### 历史波动率（Realized Volatility / HV）

```
HV = std(daily_returns) × √252

常用周期：
- HV5：过去5日年化波动率
- HV20：过去20日年化波动率（月度）
- HV60：过去60日年化波动率
- HV120：过去120日年化波动率

波动率聚簇特征：
- 高波动率后面跟着高波动率
- 低波动率后面跟着低波动率
- 这意味着可以用HV预测短期IV
```


### 隐含波动率（Implied Volatility / IV）

```
IV是从期权市场价格反推的波动率
已知：S, K, T, r, 期权价格P
求解：σ 使得 BS(S,K,T,r,σ) = P

性质：
- IV是市场对未来波动率的预期
- IV通常 > HV（风险溢价）
- IV是前瞻性的，HV是后顾性的
```

### IV vs HV的缺口分析

```
IV - HV 的含义：

IV >> HV（IV高估）：
  → 市场预期波动率上升
  → 事件前（政策、财报、假期）
  → 可以考虑卖出波动率

IV ≈ HV（合理定价）：
  → 期权定价合理
  → 根据方向判断

IV << HV（IV低估，罕见）：
  → 市场忽视风险
  → 可以考虑买入波动率

A股经验值：
- 50ETF期权IV - HV 长期均值约3-5个百分点
- 超过8个百分点：IV偏贵
- 低于1个百分点：IV偏便宜
```


## 波动率偏斜（Volatility Skew）

### 什么是偏斜

```
相同到期日，不同行权价的IV不同：

行权价        IV
低行权(Put)   高    ← 恐慌需求推高Put IV
ATM           中
高行权(Call)  中高  ← 肥尾效应

A股50ETF期权偏斜特征：
- 负偏斜（左偏）：低行权价Put的IV更高
- 偏斜度更陡（A股恐慌性需求更强）
- 事件前后偏斜会明显加剧
```

### 偏斜交易

```
偏斜过高时：
  → 卖出低行权Put + 买入ATM Put（做窄偏斜）
  → 或卖出低行权Put价差

偏斜过低时：
  → 买入低行权Put + 卖出ATM Put（做宽偏斜）

A股经验：
- 重大政策前偏斜走陡 → 事件后偏斜回落
- 可以在事件前卖出偏斜（风险高！）
- 更安全：在偏斜极端时开仓
```


## 波动率交易策略

### 策略一：做多波动率

```
适用场景：
- 预期市场大幅波动
- IV低于HV（波动率被低估）
- 重大事件前

工具：
1. 买入跨式（Long Straddle）
   - 买ATM Call + ATM Put
   - 成本高但盈亏平衡点明确
   - 盈亏平衡 = K ± 总权利金

2. 买入宽跨式（Long Strangle）
   - 买OTM Call + OTM Put
   - 成本低于跨式但需要更大波动

3. 买入日历价差（Long Calendar Spread）
   - 买远月ATM + 卖近月ATM
   - 赚取时间价值差异
   - IV上升时获利
```

### 策略二：做空波动率

```
适用场景：
- IV显著高于HV
- 市场恐慌后IV回落
- 预期窄幅震荡

工具：
1. 卖出跨式/宽跨式
   - 风险无上限（需严格止损！）

2. 铁鹰式（Iron Condor）
   - 卖OTM Put + 买更OTM Put
   - 卖OTM Call + 买更OTM Call
   - 风险有限，收益有限
   - A股最推荐的卖波策略

3. 卖出备兑看涨（Covered Call）
   - 持有ETF + 卖出Call
   - 降低持仓成本，上限收益
```

### 策略三：波动率均值回归

```
核心逻辑：波动率有均值回归特征

步骤：
1. 计算HV20的百分位数（过去2年）
2. HV百分位 < 20%：买入波动率（跨式）
3. HV百分位 > 80%：卖出波动率（铁鹰）
4. 中间区域：不交易

A股优化：
- 考虑IV百分位而非HV
- 加入事件日历过滤（政策日、财报期不卖波）
- 控制Delta中性（避免方向暴露）
```


## 波动率期限结构

```
正常市场（Contango）：
  近月IV < 远月IV
  → 卖远月买近月（日历价差多头）

异常市场（Backwardation）：
  近月IV > 远月IV
  → 市场恐慌
  → 买远月卖近月（反向日历价差）

A股波动率期限结构：
- 正常状态：远月 > 近月（contango）
- 恐慌时：近月飙升，期限结构反转
- 这种反转是买入远月卖近月的机会
```


## 波动率与A股事件

| 事件 | IV反应 | 策略 |
|------|--------|------|
| 中央经济工作会议 | IV上升 | 事件前卖IV（谨慎） |
| GDP/CPI数据 | IV小幅上升 | 数据公布后IV回落 |
| 春节长假 | IV上升 | 节前最后1-2天IV回落 |
| 美联储议息 | IV上升 | 影响相对间接 |
| 两会 | IV小幅上升 | 政策预期 |
| 财报季 | 个股IV飙升 |ETF IV影响较小 |

**规则**：
- 事件前IV升高 → 买IV成本高
- 事件后IV崩溃 → 卖IV的好时机
- 不要在事件前买跨式（IV太高），除非预期波动极大
