# 对冲策略

> 对冲不是消除风险，而是选择性承担你愿意承担的风险

## 对冲的核心思想

```
总风险 = 系统性风险 (Beta) + 特质性风险 (Alpha)

对冲的目标：
- 去除不想要的系统性风险 → 只赚取Alpha
- 或转移特定风险到愿意承担的人

常用工具：
- 股指期货：对冲市场风险
- ETF期权：对冲下行风险
- 行业ETF：对冲行业风险
```


## 策略一：股指期货对冲

### 基本原理

```
持有股票多头 + 做空股指期货 = 市场中性

对冲比率 = 组合Beta × 组合市值 / 期货合约价值

例如：
- 持有100万股票组合，Beta=1.2
- IF合约价值 = 3800 × 300 = 114万
- 需要卖空手数 = 1.2 × 100万 / 114万 ≈ 1.05手
- 实际操作：卖空1手IF
```

### 常用股指期货

| 合约 | 代码 | 乘数 | 标的 | 适合对冲 |
|------|------|------|------|---------|
| IF | 沪深300 | 300元/点 | 沪深300 | 大盘股组合 |
| IC | 中证500 | 200元/点 | 中证500 | 中盘股组合 |
| IM | 中证1000 | 200元/点 | 中证1000 | 小盘股组合 |
| IH | 上证50 | 300元/点 | 上证50 | 大盘蓝筹组合 |

### 对冲成本

```
股指期货对冲成本：
1. 保证金占用：约10-15%（不构成支出，但占用资金）
2. 基差成本：期货可能与现货有升贴水
   - 期货升水（正基差）：做空方承担基差收敛成本
   - 期货贴水（负基差）：做空方可能获得基差收益
3. 换月成本：合约到期换月时的滑点
4. 跟踪误差：组合与指数不完全匹配

A股年化对冲成本估算：
- IF：约0-2%（视基差而定）
- IC：约2-6%（IC长期贴水）
- IM：约3-8%（IM贴水更大）

IC/IM经常深贴水 → 做空中证500/1000期货有基差收益
但这也意味着对冲成本可能较高（贴水转为升水时换月损失）
```


## 策略二： Protective Put（保护性看跌）

### 基本原理

```
持有ETF + 买入看跌期权 = 为持仓买保险

例如：
- 持有10000份510300（沪深300ETF）
- 买入1张510300 Put，行权价3.8（ATM）
- 权利金：约0.05元/份 = 500元/张

结果：
- 市场上涨：享受涨幅，损失500元权利金
- 市场下跌：最多亏到3.8元，下行风险被锁定

成本：相当于总市值的1-2%（保险费）
```

### 期权选择

| 选择 | 成本 | 保护程度 | 适合 |
|------|------|---------|------|
| ATM Put | 高（2-3%） | 充分 | 急跌保护 |
| 5% OTM Put | 中（1-2%） | 一般 | 常规保护 |
| 10% OTM Put | 低（0.5-1%） | 弱 | 极端风险保护 |

**降低成本的变体**：
- **领型策略（Collar）**：买Put + 卖Call → 用卖Call的钱买Put
- **Put价差**：买ATM Put + 卖OTM Put → 降低权利金


## 策略三：配对对冲（行业中性）

### 基本原理

```
做多行业内强势股 + 做空行业ETF = 行业中性

例如：
- 做多贵州茅台 + 做空消费ETF
- Alpha = 茅台超额收益（vs 消费ETF）
- 对冲掉了消费行业的系统性风险

A股实现：
- 做多股票 + 做空行业ETF（融券）
- 或：做多股票 + 做空行业股指期货
```


## 策略四：波动率对冲

### VIX类似指标

```
A股没有官方VIX，但可以：
1. 从50ETF期权隐含波动率计算iVIX
2. 使用中国波指iVIX（已暂停，需自行计算）
3. 使用50ETF期权ATM波动率作为代理

波动率策略：
- 预期市场大跌 → 买入跨式/宽跨式（做多波动率）
- 预期市场平稳 → 卖出宽跨式（做空波动率）
- IV > HV + 风险溢价 → 考虑卖出波动率
```


## 对冲效果评估

### 评估指标

```python
def evaluate_hedge(portfolio_returns, hedge_returns):
    """
    评估对冲效果
    """
    # 对冲后收益
    hedged_returns = portfolio_returns + hedge_returns * hedge_ratio
    
    # 对冲前后的对比
    before = {
        'vol': portfolio_returns.std() * np.sqrt(252),
        'max_dd': max_drawdown(portfolio_returns),
        'beta': calculate_beta(portfolio_returns, market_returns)
    }
    
    after = {
        'vol': hedged_returns.std() * np.sqrt(252),
        'max_dd': max_drawdown(hedged_returns),
        'beta': calculate_beta(hedged_returns, market_returns)
    }
    
    return {
        'vol_reduction': before['vol'] - after['vol'],
        'dd_reduction': before['max_dd'] - after['max_dd'],
        'beta_reduction': before['beta'] - after['beta'],
        'hedge_cost': -hedge_returns.mean() * 252  # 对冲的年化成本
    }
```

### 理想 vs 现实

| 指标 | 理想对冲 | 现实对冲 |
|------|---------|---------|
| Beta | 0 | 0.1-0.3 |
| 波动率降低 | 80%+ | 50-70% |
| 对冲成本 | 0 | 1-3%年化 |
| Alpha保留 | 100% | 被成本侵蚀 |


## A股对冲的特殊问题

### 1. 融券限制

```
A股融券困难：
- 融券池有限（主要是大盘蓝筹和ETF）
- 融券利率高（年化6-10%）
- 融券可能被召回

替代方案：
- 股指期货做空（流动性好）
- ETF期权做保护
- 行业ETF融券（比个股好融）
```

### 2. 期货贴水

```
IC/IM长期贴水：
- 中证500/1000股指期货长期低于现货
- 意味着做空IC/IM有基差收益（对冲方赚）
- 但贴水大小波动，贴水收窄时换月亏损

贴水年化估算：
- IF：0-2%
- IC：5-10%
- IM：5-12%

对策略的影响：
- Alpha策略对冲后，还要赚取IC贴水的成本
- 所以A股市场中性策略的Alpha门槛更高
```

### 3. 对冲时效性

```
- 股指期货：实时对冲
- ETF期权：实时对冲（但流动性集中在ATM附近）
- 融券：T+1才能卖出
- 期货合约到期：需要换月（近远月切换时的基差风险）
```
