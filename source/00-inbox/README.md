# 📥 新材料收件箱

> 把你找到的好材料放进这个文件夹，后续再分类归档到对应目录。

## 使用方法

1. 把 PDF、网页截图、笔记、链接等直接丢进这里
2. 文件命名建议带上日期和关键词：`2026-06-12-动量策略笔记.md`
3. 积累到一定量后，整理归档到对应的知识库目录：

## 归档目标

| 归档到 | 内容类型 |
|--------|---------|
| `01-classic-strategies/` | 策略论文、策略回测报告、因子研究 |
| `02-technical-analysis/` | K线教程、技术指标说明、图表形态 |
| `03-investment-fundamentals/` | 市场规则、估值方法、组合管理 |
| `04-hedging-derivatives/` | 期权策略、对冲案例、希腊字母 |
| `05-execution-costs/` | 交易成本、滑点研究、微观结构 |
| `06-reading-list/` | 推荐书籍、课程、博客 |

## 支持的格式

- Markdown `.md`
- PDF `.pdf`
- 图片 `.png` `.jpg`
- Jupyter Notebook `.ipynb`
- 数据文件 `.csv` `.xlsx`
