# 基本面与估值基础

> 量化不只是看K线——基本面是定价的第一性原理

## 基本面分析框架

### 自上而下（Top-Down）

```
宏观经济 → 行业景气 → 公司基本面 → 估值 → 交易时机

宏观：GDP、CPI、利率、汇率、PMI
行业：产业链位置、竞争格局、政策环境
公司：盈利能力、成长性、财务健康
估值：绝对估值、相对估值
```

### 自下而上（Bottom-Up）

```
公司基本面 → 估值 → 行业对比 → 关注宏观风险

适用于：选股型量化策略
核心：找到被市场低估的公司
```


## 核心财务指标

### 盈利能力

| 指标 | 公式 | 含义 | A股关注点 |
|------|------|------|----------|
| ROE | 净利润/净资产 | 股东回报率 | 最重要，连续ROE>15%为优 |
| ROA | 净利润/总资产 | 资产回报率 | 区分轻重资产行业 |
| 毛利率 | 毛利/营收 | 产品竞争力 | 行业差异大，同行业比较 |
| 净利率 | 净利润/营收 | 盈利质量 | 排除非经常性损益 |

### 成长性

| 指标 | 公式 | 含义 |
|------|------|------|
| 营收增长率 | (本期营收-上期)/上期 | 业务扩张速度 |
| 净利润增长率 | (本期净利-上期)/上期 | 盈利增长 |
| 扣非净利增长率 | 扣除非经常损益后 | 真实盈利增长 |

### 财务健康

| 指标 | 公式 | 含义 | 风险线 |
|------|------|------|--------|
| 资产负债率 | 总负债/总资产 | 杠杆水平 | >70%警戒 |
| 流动比率 | 流动资产/流动负债 | 短期偿债 | <1危险 |
| 速动比率 | (流动资产-存货)/流动负债 | 快速偿债 | <0.5危险 |
| 经营现金流/净利 | — | 盈利质量 | <0.5谨慎 |


## 估值方法

### 绝对估值

**DCF（现金流折现）**：
```
企业价值 = Σ FCF_t / (1+WACC)^t + 终值/(1+WACC)^n

WACC = E/(E+D) × Re + D/(E+D) × Rd × (1-Tc)

其中：
- FCF = 自由现金流
- WACC = 加权平均资本成本
- 终值 = FCF_n × (1+g) / (WACC-g)

优点：理论基础扎实
缺点：输入参数敏感（WACC和增长率极小变化导致估值巨大变化）
```

**股息折现模型（DDM）**：
```
P = D1 / (r - g)

其中：
- D1 = 下一年预期股息
- r = 要求回报率
- g = 股息增长率

适合：高股息率股票（银行、公用事业）
A股特点：分红率低，DDM适用性有限
```

### 相对估值

**PE（市盈率）**：
```
PE = 股价 / 每股收益

分类：
- 静态PE = 当前股价 / 上年EPS
- 动态PE(TTM) = 当前股价 / 最近12个月EPS
- 预期PE = 当前股价 / 预测EPS

A股解读：
- PE < 15：可能低估（银行常用）
- PE 15-25：合理区间
- PE > 40：成长股或高估
- PE < 0：亏损公司

注意：
- 周期股PE失真（高PE可能是周期底部）
- 扣非PE比静态PE更有参考价值
- 同行业PE比较才有意义
```

**PB（市净率）**：
```
PB = 股价 / 每股净资产

适合：银行、保险、重资产行业
A股解读：
- PB < 1：破净，可能低估
- PB 1-3：合理区间
- PB > 5：高估或轻资产高ROE

PB-ROE框架：
- 高ROE + 低PB = 最优组合
- 低ROE + 高PB = 价值陷阱
```

**PS（市销率）**：
```
PS = 股价 / 每股营收

适合：亏损期的成长股（互联网、SaaS）
A股：科创板公司常用PS估值
```

**PEG（市盈增长比）**：
```
PEG = PE / 净利润增长率(%)

Peter Lynch规则：
- PEG < 1：低估
- PEG = 1：合理
- PEG > 2：高估

问题：增长率预测极不稳定
```


## A股特有的基本面因子

### 北向资金因子

```
沪股通/深股通：
- 北向资金净流入 = 外资买入信号
- 北向资金偏好：高ROE、大市值、消费白马
- 因子方向：北向净流入比例 → 正收益

量化使用：
- 北向持股比例变化
- 北向净流入数据（日频）
```

### A股特色财务因子

| 因子 | 来源 | 逻辑 |
|------|------|------|
| 业绩预告超额 | 业绩预告 vs 一致预期 | 超预期 |
| 研报覆盖度 | 券商研报数量 | 关注度 |
| 机构持仓变化 | 基金季报 | 聪明钱 |
| 高送转 | 分红送股方案 | A股独有 |
| 限售股解禁 | 解禁日历 | 供给冲击 |

### 排雷清单

```
A股基本面排雷：
□ 是否ST/*ST
□ 是否连续两年亏损
□ 是否存在重大诉讼
□ 审计意见是否非标
□ 商誉占净资产比例 > 30%
□ 经营现金流是否持续为负
□ 应收账款增速是否远超营收增速
□ 关联交易占比是否过高
□ 股权质押比例是否过高（>50%）
□ 是否存在退市风险警示

量化实现：
- 每月/每季度更新排雷因子
-排雷因子 = 1（通过）或 0（不通过）
- 不通过的股票直接从池中剔除
```


## 估值与策略结合

```
估值因子在量化策略中的使用：

1. 价值策略：买入低PE/PB组合
   - 月度换仓，IC约0.03-0.05
   - A股价值因子近年来表现较弱

2. 价值+动量策略：低估值+高动量
   - 全球最经典的Smart Beta组合
   - 价值与动量负相关，分散化效果好

3. 价值+质量策略：低估值+高ROE
   - 避免价值陷阱（低估值但低质量）
   - A股表现较好

4. 估值择时策略：整体估值水平判断
   - 沪深300 PE历史分位数
   - 高分位减仓、低分位加仓
```
