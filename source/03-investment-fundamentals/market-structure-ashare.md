### ETF交易要点

```
一级市场（申购赎回）：
- 申购：用一篮子股票换ETF份额
- 赎回：用ETF份额换一篮子股票
- 门槛：一般30万-100万份起
- 用途：套利（折溢价）

二级市场（买卖）：
- 像股票一样在交易所买卖
- T+0回转（当日买入可当日卖出ETF份额）
- 佣金与股票相同，无印花税
```

## A股量化的特殊考虑

### 1. T+1的影响

```
- 当日买入不可卖出 → 隔夜风险
- 不能做日内回转（除ETF）
- 影响策略：
  → 止损必须在次日执行
  → 高频策略受限
  → 隔夜跳空风险必须纳入模型
```

### 2. 涨跌停板的影响

```
- 涨停板封板 = 买入困难/无法买入
- 跌停板封板 = 卖出困难/无法卖出
- 连续涨跌停 = 流动性风险
- 量化影响：
  → 回测需模拟涨跌停无法成交
  → 涨跌停次日有延续效应
  → 涨停突破策略需专门设计
```

### 3. 集合竞价机制

```
9:15-9:20：可挂单可撤单（信息噪声大）
9:20-9:25：可挂单不可撤单（真实意向）
9:25-9:30：不接受申报（静默期）
14:57-15:00：收盘集合竞价

量化利用：
- 9:20-9:25的委托信息可用于信号
- 开盘跳空缺口 = 隔夜信息的量化指标
```

### 4. 融券与做空限制

```
A股做空困难：
- 融券池有限（主要限大盘股）
- 融券利率高（年化6-10%）
- 转融通限制
- 股指期货对冲是主要替代

量化策略调整：
- 改用纯多头+股指期货对冲
- 市场中性策略成本更高
- 只做多的因子策略更实际
```

### 5. 退市与ST规则

```
退市新规（2020年修订）：
- 连续20个交易日收盘价低于1元
- 连续两年亏损+年营收低于1亿元
- 重大违法强制退市
- 财务造假退市

量化策略必须：
- 排除ST、*ST股票
- 排除股价低于2元的股票
- 监控退市风险警示
```
