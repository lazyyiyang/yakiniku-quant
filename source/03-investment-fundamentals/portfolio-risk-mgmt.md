# 组合构建与风险管理

> 策略只是第一步，如何把策略组合起来并控制风险才是长期生存的关键

## 组合构建框架

### 从信号到组合

```
Alpha信号（因子得分）
    ↓
风险中性化（行业、市值中性化）
    ↓
组合优化（约束条件下最优化权重）
    ↓
执行（考虑成本、流动性）
    ↓
风控监控（敞口限制、止损）
```

### 权重分配方法

| 方法 | 公式/逻辑 | 优点 | 缺点 |
|------|-----------|------|------|
| 等权重 | 1/N | 简单、稳健 | 忽略风险差异 |
| 市值加权 | 按市值占比 | 低换手、流动性好 | 大盘股集中 |
| 因子加权 | 按因子得分加权 | Alpha最大化 | 可能集中风险 |
| 最小方差 | min σ_p | 低波动 | 估计误差大 |
| 风险平价 | 1/σ_i | 风险等贡献 | 可能过度集中于低波动资产 |
| 等风险贡献 | ERC | 均衡风险 | 计算复杂 |

### 风险平价示例

```python
def risk_parity_weights(volatilities, correlations):
    """
    风险平价：每个资产对组合风险的贡献相等
    
    简化版（忽略相关性）：
    w_i ∝ 1 / σ_i
    
    归一化后：w_i = (1/σ_i) / Σ(1/σ_j)
    """
    inv_vols = 1.0 / volatilities
    weights = inv_vols / inv_vols.sum()
    return weights

# 示例：A股主要指数ETF
# 沪深300 σ=22%, 中证500 σ=28%, 创业板 σ=30%
# 风险平价权重：约 39% / 31% / 30%
```


## 风险管理

### 单笔风险控制

```
止损规则：
- 固定比例止损：单笔最大亏损 = 总资金的2%
- 波动率止损：入场价 - K × ATR(14)，K通常=2
- 时间止损：如果N日内未盈利，平仓

仓位管理：
- Kelly公式（简化版）：f = (p×b - (1-p)) / b
  p = 胜率, b = 盈亏比
- 半Kelly（实战）：使用 Kelly/2 避免过度杠杆
- 固定风险法：仓位 = 风险金额 / 止损幅度
```

### 组合风险控制

| 风险维度 | 指标 | 限制典型值 |
|----------|------|-----------|
| 最大回撤 | 从峰值到谷值的最大损失 | < 15-20% |
| 波动率 | 年化收益率标准差 | 目标10-20% |
| 行业集中度 | 单行业最大权重 | < 20-30% |
| 个股集中度 | 单股最大权重 | < 5-10% |
| Beta暴露 | 组合Beta vs 基准 | 中性策略 ≈ 0 |
| 因子暴露 | 单因子Z-score | | < 0.5 |

### 止损与回撤管理

```python
def max_drawdown(equity_curve):
    """
    计算最大回撤
    """
    cummax = equity_curve.cummax()
    drawdown = (equity_curve - cummax) / cummax
    max_dd = drawdown.min()
    max_dd_end = drawdown.idxmin()
    max_dd_start = equity_curve[:max_dd_end].idxmax()
    
    return {
        'max_drawdown': max_dd,
        'start_date': max_dd_start,
        'end_date': max_dd_end,
        'recovery_date': None  # 需额外计算
    }
```

**回撤分级管理**：
| 回撤 | 行动 |
|------|------|
| < 5% | 正常运行 |
| 5-10% | 审查策略，减少新仓位 |
| 10-15% | 减仓50%，全面审查 |
| 15-20% | 清仓止损，策略暂停 |
| > 20% | 紧急风控，需重新验证策略 |

## 多策略组合

### 策略分散化

```
策略组合的核心：低相关性
- 策略A：A股量价动量（趋势型）
- 策略B：价值因子（逆转型）
- 策略C：可转债套利（事件型）
- 策略D：ETF折溢价套利（均值回归型）

相关性越低 → 组合Sharpe越高
理想状态：策略间相关性 < 0.3
```

### 资金分配

```
方法一：等风险分配
- 每个策略风险贡献相等
- 高波动策略分配更少资金

方法二：等权重分配
- 每个策略分配相同资金
- 简单但可能风险不均衡

方法三：Kelly分配
- f_i = (Sharpe_i / σ_i) / 2
- 按风险调整后收益分配
```


## 基准与绩效评估

### 绩效指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 年化收益率 | (1+R)^252 - 1 | 绝对收益 |
| 夏普比率 | (R - R_f) / σ | 风险调整收益 |
| 索提诺比率 | (R - R_f) / σ_down | 下行风险调整 |
| 最大回撤 | min(净值/前峰值-1) | 最坏情况 |
| Calmar比率 | 年化收益 / 最大回撤 | 收益回撤比 |
| 胜率 | 盈利次数/总次数 | 准确率 |
| 盈亏比 | 平均盈利/平均亏损 | 赔率 |
